# Timetable Clash Detector

A responsive single-page web tool built to solve student course enrollment conflicts. It lets users register lectures by day and time to verify that selected classes do not overlap.

## Problem Statement
When registering for semester courses across different departments, class timetables frequently overlap. Manually cross-referencing multiple course schedule PDFs often leads to overlooked clashes, resulting in dropped courses during add/drop week. This tool validates time slots client-side and alerts the user when overlaps occur.
